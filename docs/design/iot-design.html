🧩 Component Catalog

Detailed specifications for every hardware component in the GridShield system

🧠
ESP32 DevKit V1
ESP32-D0WD-V3 · 30-pin

Main controller with dual-core processor, integrated WiFi/BLE, hardware crypto accelerator, and 34 programmable GPIO pins.

CPU: 240MHz
RAM: 520KB
Flash: 4MB
ADC: 18ch 12-bit
UART: 3 ports
I2C: 2 buses
VCC: 3.3V
USB: CP2102
⚡
ACS712 Current Sensor
30A Module · Hall Effect

Hall-effect based linear current sensor. Measures AC/DC up to 30A with 66mV/A sensitivity. Output centered at VCC/2 (1.65V).

Range: ±30A
Sens: 66mV/A
VCC: 5V
Out: Analog
Pin: GPIO34
Bus: ADC1_CH6
🔌
ZMPT101B Voltage Sensor
AC Voltage Transformer

Precision AC voltage transformer module. Measures up to 250VAC with isolation. Output through voltage divider to 0-3.3V range.

Range: 0-250V AC
Ratio: 1:1
VCC: 5V
Out: Analog
Pin: GPIO35
Bus: ADC1_CH7
📊
PZEM-004T v3.0
AC Energy Meter Module

Multi-function AC energy meter. Measures voltage, current, power, energy, frequency, and power factor via Modbus-RTU over UART.

V: 80-260VAC
I: 0-100A (CT)
Proto: Modbus
Baud: 9600
RX: GPIO16
TX: GPIO17
🌡️
DS18B20 Temperature
Waterproof Probe · OneWire

Digital temperature sensor with ±0.5°C accuracy. OneWire protocol requires single data line with 4.7kΩ pull-up resistor.

Range: -55~125°C
Acc: ±0.5°C
Res: 12-bit
Proto: OneWire
Pin: GPIO27
Pull: 4.7kΩ
📐
MPU6050 IMU
6-Axis · Accelerometer + Gyro

6-axis motion sensor for physical tamper detection. I2C interface detects shock, tilt, and orientation changes.

Accel: ±16g
Gyro: ±2000°/s
Proto: I2C
Addr: 0x68
SDA: GPIO21
SCL: GPIO22
🔴
Tamper Micro Switch
Normally-Closed · Panel Mount

Casing intrusion detector. NC contact opens when meter cover is removed, triggering ISR on falling edge with debounce logic.

Type: NC
Trigger: FALLING
Pin: GPIO4
Pull: 10kΩ UP
Debounce: 50ms
ISR: Yes
💡
Status LEDs (×3)
3mm Diffused · R/A/G

Visual status indicators. Green=OK, Amber=Warning, Red=Tamper Alert. Each with 220Ω current-limiting resistor.

Green: GPIO25
Amber: GPIO26
Red: GPIO14
R: 220Ω each
If: 20mA
Vf: 2.0-3.2V
🔋
Backup Capacitor
1000µF 16V Electrolytic

Emergency power backup for tamper alert transmission during power cut. Provides ~2-3 seconds of operation at minimal power.

Cap: 1000µF
Voltage: 16V
Type: Electrolytic
Mon: GPIO32

🔗 Connection Paths Detail

Step-by-step wiring instructions for each sensor connection

🔴 Tamper Switch → ESP32
DIGITAL INPUT · ISR · GPIO4
  • Switch COM terminal → ESP32 GPIO4
  • Switch NC terminal → GND rail
  • 10kΩ resistor: GPIO4 → 3V3 (pull-up)
  • Firmware: INPUT_PULLUP, ISR FALLING edge
  • Debounce: 50ms software filter
📊 PZEM-004T → ESP32
UART2 · MODBUS-RTU · 9600 BAUD
  • PZEM TX → ESP32 GPIO16 (RX2)
  • PZEM RX → ESP32 GPIO17 (TX2)
  • PZEM 5V → 5V rail (VIN)
  • PZEM GND → GND rail
  • CT clamp around AC live wire
📐 MPU6050 → ESP32
I2C BUS · ADDRESS 0x68 · 400kHz
  • MPU SDA → ESP32 GPIO21
  • MPU SCL → ESP32 GPIO22
  • MPU INT → ESP32 GPIO13
  • MPU VCC → 3V3 rail
  • MPU GND → GND rail
  • MPU AD0 → GND (addr 0x68)
🌡️ DS18B20 → ESP32
ONEWIRE · GPIO27 · PARASITIC OK
  • DS18B20 Data (yellow) → ESP32 GPIO27
  • DS18B20 VCC (red) → 3V3 rail
  • DS18B20 GND (black) → GND rail
  • 4.7kΩ resistor: GPIO27 → 3V3 (pull-up)
⚡ ACS712 → ESP32
ADC1_CH6 · GPIO34 · ANALOG INPUT
  • ACS712 OUT → ESP32 GPIO34
  • ACS712 VCC → 5V rail
  • ACS712 GND → GND rail
  • AC load wire through sensor hole
  • Output: VCC/2 ± (66mV × Amps)
🔌 ZMPT101B → ESP32
ADC1_CH7 · GPIO35 · VOLTAGE DIVIDER
  • ZMPT OUT → Voltage Divider input
  • R1=100kΩ from ZMPT OUT to node
  • R2=10kΩ from node to GND
  • Divider node → ESP32 GPIO35
  • ZMPT VCC → 5V, GND → GND
💡 Status LEDs → ESP32
GPIO OUTPUT · 220Ω SERIES
  • Green LED anode → 220Ω → GPIO25
  • Amber LED anode → 220Ω → GPIO26
  • Red LED anode → 220Ω → GPIO14
  • All LED cathodes → GND rail
🔋 Power Monitoring → ESP32
ADC · GPIO32 + GPIO33
  • Backup cap + → voltage divider → GPIO32
  • Solar panel V+ → divider → GPIO33
  • Divider: R1=100kΩ, R2=10kΩ
  • Max input to ADC: 3.3V

🔧 Assembly Guide

Step-by-step wiring procedure for building a GridShield node

1

Prepare Power Rails

Place ESP32 on breadboard center. Connect 3V3 and GND pins to power rails. Add 5V from VIN pin to separate rail. Add 100nF decoupling cap near each sensor VCC pin.

2

Wire I2C Bus (MPU6050)

Connect SDA→GPIO21, SCL→GPIO22, INT→GPIO13. Add 4.7kΩ pull-ups on SDA and SCL to 3V3. Power from 3V3 rail. Tie AD0 to GND for address 0x68.

SDA→21SCL→22INT→13
3

Wire OneWire Bus (DS18B20)

Connect data wire (yellow) to GPIO27. Add 4.7kΩ pull-up from GPIO27 to 3V3. Connect red wire to 3V3, black to GND.

DATA→274.7kΩ→3V3
4

Wire UART2 (PZEM-004T)

Cross-connect: PZEM TX→ESP GPIO16 (RX2), PZEM RX→ESP GPIO17 (TX2). Power PZEM from 5V rail. Route CT clamp around AC live wire. ⚠️ AC voltage connections require proper isolation.

TX→RX2(16)RX→TX2(17)
5

Wire ADC Sensors (ACS712 + ZMPT101B)

ACS712 OUT→GPIO34 directly (output is 0-3.3V range). ZMPT101B: add voltage divider (100kΩ/10kΩ) before GPIO35. Both powered from 5V rail.

ACS→34ZMPT→div→35
6

Wire Tamper Switch

Connect NC terminal to GPIO4, COM to GND. Add 10kΩ pull-up from GPIO4 to 3V3. Configure ISR for FALLING edge with 50ms debounce in firmware.

NC→GPIO4COM→GND10kΩ→3V3
7

Wire Status LEDs

For each LED: anode→220Ω resistor→GPIO pin, cathode→GND. Green→GPIO25, Amber→GPIO26, Red→GPIO14.

🟢→25🟡→26🔴→14
8

Add Backup Power + Monitoring

Connect 1000µF capacitor across 5V/GND rail. Add voltage divider (100kΩ/10kΩ) from cap to GPIO32 for monitoring. Optional: solar panel divider to GPIO33.

Cap→5V/GNDMon→32

🛡️ 3-Layer Security Architecture

Defense-in-depth approach mapped to hardware components

Layer 1 — Physical
Tamper Detection Hardware
Hardware-level intrusion detection using multiple sensor modalities
  • Micro-switch casing sensor (GPIO4, ISR + 50ms debounce)
  • MPU6050 shock & tilt detection (I2C 0x68, INT→GPIO13)
  • DS18B20 thermal anomaly monitoring (OneWire GPIO27)
  • Power-cut detection via backup cap ADC (GPIO32)
  • GPIO wake-on-tamper from deep sleep
Layer 2 — Network
Cryptographic Security
Production-grade encryption and authentication for all communications
  • ECDSA P-256 signature (micro-ecc library)
  • AES-256-GCM via ESP32 HW accelerator
  • HKDF key derivation + rotation
  • MQTT over TLS 1.2 (WiFi 802.11n)
  • Secure Boot v2 + Flash encryption
Layer 3 — Application
Analytics & Detection
Intelligent anomaly detection with edge processing
  • Statistical anomaly detector (σ-deviation)
  • PZEM-004T energy data analysis
  • Cross-layer threat correlation
  • Forensic event logging (circular buffer)
  • Evidence preservation with hash chain
